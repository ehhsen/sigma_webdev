## 🚀 How to Use

No setup needed. Just open any `index.html` in your browser:

```bash
git clone https://github.com/ehhsen/sigma_webdev.git
cd sigma_webdev/video02
# open index.html in browser
```

Or use the **Live Server** extension in VS Code for hot reload.
